Undo — scénarios de démo

Petites apps locales, 100 % reproductibles. Ctrl+Maj+E : expirer la session · Ctrl+Maj+R : réinitialiser.

  1. 1. Formulaire perdu — un dossier administratif qui se vide quand la « session expire ».
  2. 2. Réglage oublié — un panneau de paramètres ; une combinaison casse l'app.
  3. 3. Contenu supprimé — une liste de notes avec corbeille.
  4. 4. Compte rendu perdu — une fiche CRM sans sauvegarde auto, effacée à l'expiration.
  5. 5. D'une app à l'autre — un mail (Safari) dont les infos vont dans le formulaire (Brave).

Lance python -m undo demo puis ouvre localhost:8765.
